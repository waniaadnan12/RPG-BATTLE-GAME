# ⚔️ RPG Battle Game

![RPG Battle Game](https://img.itch.zone/aW1nLzc2NTUxMTYucG5n/original/XWbalo.png)

A simple **text-based RPG Battle Game** made with Python.

In this game, you play as a **Hero** and fight against a **Goblin**. You can attack the goblin or use a potion to restore your health. The battle continues until either the hero or the goblin is defeated.

---

## 🎮 Game Features

- 🧙 Play as a Hero
- 👹 Fight against a Goblin
- ⚔️ Attack the enemy
- 🧪 Use a health potion
- ❤️ Health system
- 🎲 Random damage system
- 🏆 Win or lose conditions
- 📊 Display player and enemy stats

---

## 🛠️ Technologies Used

- **Python**
- `random` module
- Dictionaries
- Functions
- Loops
- Conditional statements
- User input
